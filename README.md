# Évala · La saison des lutteurs

Jeu de lutte et d'aventure en navigateur, inspiré de l'Évala, la lutte initiatique kabyè de la Kozah (région de la Kara, Togo).

- **Aventure** : trois Évala, de 2026 à 2028. Préparation au village, tableau à huit cantons en élimination directe, cérémonie de clôture.
- **Arcade** : la tournée des cantons, huit adversaires d'affilée.
- **Entraînement** : la leçon de Pyabalo et des combats libres.

Le jeu ne montre que la partie publique de l'Évala. Les rites réservés aux initiés restent hors champ.

```bash
npm install
npm run dev   # http://localhost:5175
npm test
```
